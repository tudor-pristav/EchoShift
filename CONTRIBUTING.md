# Contributing

Echo Shift is a course project with its original team credits and development history preserved.

1. Follow [the development guide](docs/DEVELOPMENT.md) to configure the plain Java build.
2. Keep changes focused and describe the behavior before and after your change.
3. Run `python3 scripts/build.py test`; run `smoke` for changes to JavaFX screens or gameplay.
4. Include reproduction steps or a screenshot for visible changes.
5. Review your diff for local saves, passwords, IDE settings, and downloaded libraries before committing.

Preserve author credits and record the source and license of any new artwork or audio. Source code and original documentation use the [MIT License](LICENSE); see [third-party notices](THIRD_PARTY_NOTICES.md) for asset exclusions.
