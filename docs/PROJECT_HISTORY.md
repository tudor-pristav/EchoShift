# Project history and preserved documentation

Echo Shift was developed for Western University's COMPSCI 2212 course by group 55. The Git history records its original remote as `gitlab.sci.uwo.ca/courses/2026/01/COMPSCI2212/group55`.

The checked-out history includes GitLab branch merges and a final merge of its `main` branch. The documentation was transferred, but the GitHub root README only contained a title and one-line description, making it hard to find.

## What is present

- `EchoShift/README.md`: original course README, including authors, gameplay instructions, demo accounts, and manual IntelliJ setup.
- `EchoShift/docs/`: generated HTML Javadoc, with an `index.html` entry point.
- `EchoShift/docs.zip`: the original documentation archive.
- Git commits describing documentation and source changes before the migration.

The root README and guides in this directory provide current instructions. The original README and generated files remain intact as historical material.

## What has not been verified

A separate GitLab wiki, issues, attachments, or course submission files cannot be inferred from the Git checkout. This audit verified the local repository and history; it did not access the original GitLab server or recover a separate wiki.
